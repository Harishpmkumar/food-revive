
# Food Revive

A surplus-food marketplace that helps restaurants, bakeries, cafes,
and grocery stores sell eligible surplus food at discounted prices
for customer pickup.

## Planned Features

- Customer, vendor, and administrator roles
- Vendor approval and food listing management
- Search and filter discounted food listings
- Cart, inventory reservations, and checkout
- Razorpay test-mode payment integration
- QR-based pickup verification
- Real-time notifications using Socket.IO
- Dashboards and order management

## Technology Stack

- Frontend: React, Vite, Bootstrap 5
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Authentication: JWT and bcrypt
- Payments: Razorpay test mode
- Real-time communication: Socket.IO
- Image storage: Cloudinary
- Version control: Git and GitHub

## Project Structure

- `frontend/` - React application
- `backend/` - Express API
- `docs/` - Project documentation

## Development Status

Initial project structure created. Application setup is in progress.

## Security

Never commit `.env` files, credentials, private keys, or real customer data.
